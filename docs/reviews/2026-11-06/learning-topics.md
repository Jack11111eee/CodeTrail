# 独立学习主题：第一版

已新增“新建学习主题 → 第一个问题 → 独立讲解 → 主题内追问”的流程。

- 阅读页顶部提供“＋ 新建学习主题”。名称可留空，先保存为“未命名主题”。创建草稿不调用模型。
- 首个成功回答同时给出简短主题名称；手动输入的名称保留。模型未提供名称时用问题摘要兜底，不另发一次模型请求。
- 每个主题独立绑定一个会话和一个已发布分析版本。目录区分“项目讲解”和“我的学习主题”，跨分析版本仍可看到原主题，其证据保持原提交。
- 首个通过校验的回答成为主题讲解；后续追问写入这个主题自己的会话，不覆盖已保存讲解。
- 首问失败保留问题与回答记录，可重试；生成时可停止。服务重启会恢复生成状态，已有完整讲解保留。
- 支持主题删除确认和恢复，保留正文、引用及会话。原有自动生成讲解的管理功能继续保留。
- 主题与会话持久化在本机 SQLite；不修改已封存的项目文档或触发全项目重新分析。

## 真实模型验证中修复的问题

首次验证暴露了已有问答链路的问题：read_page 工具只交付正文，没有交付校验器认可的 sourceId，模型使用 OpenWiki 页面元信息中的局部来源编号，导致 evidence_check_failed。

修复后所有工具结果明确携带可引用编号，模型指令说明局部编号的区别，页面读取不再把局部编号元信息当正文交给模型。生成的 wiki 引用可按原版本打开；实际读取的新代码文件/行区间将保存经验证的定位信息，方便之后打开引用。此前只登记局部代码段的文件，也兼容打开旧问答里的整文件引用。校验失败显示原因并保留问题和草稿，不再误报连接中断。
